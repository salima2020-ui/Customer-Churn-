# Telco Customer Churn Analysis

Project Overview

This project explores the IBM Telco Customer Churn dataset using Python, Pandas, and Matplotlib.

The main goal is to analyze customer data, identify patterns, and visualize key information through different chart types.

Dataset

* Dataset: IBM Telco Customer Churn
* Rows: 7,043
* Columns: 21
* Target Variable: Churn

The dataset contains customer demographics, subscribed services, contract types, payment methods, monthly charges, total charges, and churn status.

Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

Data Visualizations

* Line Plot – Average Monthly Charges by Tenure
* Bar Chart – Customer Count by Contract Type
* Horizontal Bar Chart – Customer Count by Payment Method
* Pie Chart – Customer Churn Percentage
* Pie Chart – Customer Distribution by Internet Service

Additional Visualizations

* Histogram
* Heatmap
* Donut Chart
* Scatter Plot
* Multiple Axes

Project Objectives

* Explore customer characteristics.
* Analyze customer distribution across different categories.
* Understand customer churn proportions.
* Examine relationships between numerical variables.
* Present findings through clear and informative visualizations.
